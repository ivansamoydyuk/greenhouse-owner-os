## Isolation and reproducibility

The opt-in R3_CONNECTED_PILOT=1 preview refuses a privileged runtime, an unmarked
DB, non-loopback server, role membership, owned schema/table objects and DDL rights.
The fresh disposable database is marked r3-connected-pilot:synthetic-only:v1.
A separate bootstrap role migrates 0025 and is disabled before the HTTP runtime.
No migration or old owner-opening fixture is changed or loaded in this mode.
Original blobs are held in isolated PostgreSQL BYTEA storage; no external storage
provider is activated. Cookie auth, same-origin checks, unchanged CSP, entity fence
and bounded all-route expiry apply. No database listener is internet-facing.

The new workflow starts only its own ephemeral container and records the container
identity before migrations so always-cleanup also covers failed setup. The browser
job is a focused engineering attempt; it does not open an internet TEST preview.
No public preview is launched by this initial candidate.
